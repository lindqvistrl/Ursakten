# sys26d-sys26d-html-css-js-grupparbete-group-2

## Gruppkontrakt

-Vi kommunicerar via Teams.

# Mötestider

-Vi jobbar mellan 8.00-16.00
-Daily standup varje dag 9.00

-Be om hjälp när vi kör fast.

-Sprintplanning och backlog refining sker succeccivt under arbetsveckan vid behov, avsatt tid måndag förmiddag efter daily standups.


# Förhållning till arbete
-Jobbar på egna branches, inte direkt på Main.

-Meddelar i Teams innan vi pushar till Main.

-Tydliga commits med meddelanden.

-Om vi halkar efter så lyfter vi det.

-Öppen dialog av hur man känner över projektet. (Retrospektive)

# Samarbete
-Återkoppling på kod ger vi på tisdagar och torsdagar 15.00

-Öppna för att koda live i grupp eller enskilt. 

-Fördelar uppgifter beroende på hur vi ligger till.

-Scrum master tillsätts på måndag, 2,5 dagar, sen byter vi 

# Aktivitet
-Meddelar vid frånvaro

Arbetsuppgifter fördelas rättvist. Blir någon klar tidigare så hjälper man till där det behövs eller tar en ny uppgift från backloggen.

# Ambition
När majoriteten är överens om att uppgiften är klar. 

# Förväntningar
Vi gör så gott vi kan med den tid vi har utan att skapa en stress.
